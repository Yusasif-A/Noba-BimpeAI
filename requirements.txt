# Voice agent
#
# The whole LiveKit family is pinned to one working set, not to ranges.
#
# Two failures came from letting these float. First the TTS API moved inside the
# 1.x line - ChunkedStream._run(self) became _run(self, output_emitter) - so a
# clean container installed a newer release than the code was written against
# and every reply died with "_run() takes 1 positional argument but 2 were
# given". Then pinning only livekit-agents was not enough: the livekit SDK
# resolved to its own newest, which requires types-protobuf>=5 while
# livekit-agents 1.0.11 requires <5, and pip gave up with ResolutionImpossible.
#
# intron_stt.py and intron_tts.py subclass these APIs directly, so the framework
# version is part of this project's source. Change these together, deliberately,
# after testing - never by letting a range drift.
livekit==1.0.5
livekit-agents[openai,silero]==1.0.11
livekit-api==1.2.1
livekit-plugins-openai==1.0.11
livekit-plugins-silero==1.0.11
livekit-plugins-noise-cancellation==0.2.5
